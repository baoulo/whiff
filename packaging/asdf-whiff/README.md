# asdf-whiff

asdf plugin that installs `whiff` from [GitHub Releases](https://github.com/baoulo/whiff/releases).

```bash
asdf plugin add whiff https://github.com/baoulo/asdf-whiff.git
asdf install whiff 0.4.0
asdf global whiff 0.4.0
whiff --version
```

Publish this directory to `baoulo/asdf-whiff` (or keep developing from the monorepo path).
